# Skills Demonstrated

## Overview

This project demonstrates practical Identity and Access Management (IAM) administration through enterprise PowerShell automation within an Active Directory Domain Services (AD DS) environment.

The solution automates user provisioning, organizational hierarchy, Role-Based Access Control (RBAC), identity reporting, and employee offboarding while following enterprise administration practices.

# Project Outcome

This project demonstrates the ability to automate enterprise identity administration using PowerShell and Active Directory. Manual identity management tasks were transformed into reusable automation capable of provisioning users, configuring organizational hierarchy, implementing RBAC, generating audit reports, and automating employee offboarding while maintaining administrative logging and validation throughout the identity lifecycle.
