# Lessons Learned

## DHCP Authorization

Active Directory requires DHCP servers to be authorized before issuing leases.

---

## Scope Planning

Enterprise environments separate infrastructure devices from client devices using exclusions and reservations.

---

## Scope Options

DHCP automatically provides:

- IP Address
- Subnet Mask
- Gateway
- DNS Server
- Domain Name

---

## Reservations

Reservations ensure critical devices always receive the same IP address while still using DHCP.

---

## Troubleshooting

Verified functionality using:

- ipconfig
- Lease Renewal
- DHCP Statistics
- Event Viewer

---

## Enterprise Operations

DHCP simplifies network administration by centralizing IP address management.
