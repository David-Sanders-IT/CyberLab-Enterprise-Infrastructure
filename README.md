## Overview

CyberLab Enterprise Infrastructure is a hands-on Windows Server and Identity & Access Management portfolio designed to simulate a real enterprise environment.

The goal of this project is to develop practical experience in Windows Server administration, Active Directory, enterprise identity management, Microsoft Entra ID, Group Policy, DNS, DHCP, PowerShell automation, and enterprise security.

Every project is fully documented with screenshots, deployment notes, troubleshooting logs, architecture diagrams, and lessons learned.
