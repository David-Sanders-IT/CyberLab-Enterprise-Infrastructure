# Project 02 – Active Directory Deployment

## Project Overview

This project documents the deployment of Active Directory Domain Services (AD DS) and the promotion of Windows Server 2022 into the first Domain Controller for the CyberLab enterprise environment.

The objective was to build the identity management infrastructure used throughout the remainder of the lab. The deployment included creating a new Active Directory forest, configuring integrated DNS, and promoting the server into the first Domain Controller.

---

## Objectives

- Install Active Directory Domain Services
- Install Remote Server Administration Tools (RSAT)
- Create a new Active Directory forest
- Configure Active Directory integrated DNS
- Promote Windows Server into a Domain Controller
- Validate Active Directory functionality
- Prepare the environment for enterprise administration
