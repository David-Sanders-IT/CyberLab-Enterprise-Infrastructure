# Project 03 – Active Directory Identity Administration

## Project Overview

This project documents the creation and administration of an enterprise Active Directory environment following the deployment of the first Domain Controller.

The objective of this project was to design a scalable Organizational Unit (OU) structure, create enterprise user accounts, implement Role-Based Access Control (RBAC), create administrative identities, and organize security groups using Microsoft Active Directory best practices.

Rather than simply creating users, this project focuses on identity administration as it is performed in enterprise environments.

---

## Objectives

- Design an enterprise Organizational Unit structure
- Create departmental Organizational Units
- Create enterprise user accounts
- Create administrative accounts
- Create security groups
- Assign group memberships
- Implement Role-Based Access Control (RBAC)
- Follow the Principle of Least Privilege
- Prepare Active Directory for enterprise identity management
