# Lessons Learned

## Organizational Units Improve Administration

Separating users, groups, and computers simplifies management and Group Policy deployment.

---

## Security Groups Should Receive Permissions

Permissions should be assigned to groups rather than individual users.

---

## Administrative Accounts Should Be Separate

Administrators should use separate privileged accounts to reduce security risk.

---

## RBAC Simplifies Identity Management

Users receive permissions through security groups instead of direct assignments.

---

## Enterprise Organization Matters

A well-designed Active Directory structure scales much better than relying on default containers.

---

## Documentation Matters

Recording every deployment step improves troubleshooting, consistency, and knowledge transfer.
