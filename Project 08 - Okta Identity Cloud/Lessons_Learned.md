# Lessons Learned

This project demonstrated how enterprise organizations centralize authentication and authorization using an Identity Provider.

Key lessons included:

- Identity should be managed centrally.
- Applications should be assigned through groups.
- RBAC simplifies administration.
- Least privilege improves security.
- SaaS applications integrate into a common identity platform.
- Internal business applications can also use centralized identity.
- Enterprise IAM extends beyond user creation to include authentication, authorization, and application lifecycle management.
