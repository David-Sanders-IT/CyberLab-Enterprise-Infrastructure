# Screenshots

## Overview

This directory contains the visual documentation for **Project 07 – Microsoft Entra ID Identity Administration**.

The screenshots capture each major deployment milestone completed during the implementation of Microsoft Entra ID within the CyberLab Enterprise Infrastructure environment.

The project demonstrates cloud identity administration, delegated administration, authentication management, enterprise application integration, and modern Identity & Access Management (IAM) concepts.

Each screenshot validates a completed administrative task and serves as evidence of successful project implementation.
